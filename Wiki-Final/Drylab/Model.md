Friskoli 的模型已经超出了单纯的数学推导：它长期承担着机制探索、实验设计、DBTL、参数分析、软件架构验证，以及与微流控实验相互校验的任务。

Model 要讲的故事不在于“建立了一个复杂模型”，而是：

我们如何从一个简单的趋化模拟出发，逐渐发现早期模型的不足，并将模型发展成能够连接分子信号、细胞运动、物质扩散、底物接触与实验测量的研究体系。

应当至少提供三组真正的数据图：

- 静态剂量响应：外部糖浓度从低到高，逐层显示各个状态变量的变化。注意不要把马达偏好变化直接称为趋化灵敏度。
    
- 动态阶跃响应：输入突然升高后，比较 PTS 状态、CheA/CheY-P、motor bias 的瞬态与稳态。检查下游适应是否符合所采用的机制。
    
- 灵敏区间与不确定性：分析在不同背景浓度下，系统对小幅相对浓度变化的响应。对缺乏实测依据的参数给出合理区间，而不是只展示单一最佳参数。
    

特别建议保留 Somavanshi 2016 与 Neumann 2012 的文献—模型对应表。哪一个数学假设来自哪篇研究、哪些只是简化、哪些尚未验证，最好能够逐项追溯。

模型到软件
随着模型逐渐复杂，我们开始思考，这套计算框架是否能够服务于 Friskoli 之外的研究问题。两次项目交流中关于合成生物学属性与可迁移性的反馈，促使我们重新审视原有的纤维素降解示范体系。我们希望将底物、化学信号、细胞运动和空间环境之间的关系转化为可配置的计算模块。Friskoli-CAD 由此诞生，并逐渐从项目内部的模拟工具，发展为面向更广泛研究场景的模块化建模框架。

一个科学问题如何通过模块组合变成可计算模型，统一共性计算，注册特异机制，验证模块契约。

这解释为什么要开发 CAD，也解释了团队如何将早期单一示范模型逐渐发展成可复用的计算框架。

## From Molecular Signals to Collective Motion

### 从分子信号，到群体运动。

_An Integrated Computational Framework for Chemotaxis-Driven Active Mass Transport_

在 Friskoli 中，我们试图研究趋化降解这种跨越多个尺度的复合现象。

纤维素酶在局部产生可溶性降解产物，这些物质在空间中扩散，并可能被细菌摄取。细胞内部的信号网络将环境信息转化为运动调节，单个细胞通过游动和转向改变自己的位置，大量细胞的运动和摄取又可能改变底物附近的细胞和物质分布，进一步影响局部物质转化。

我们如何知道它们能够形成预期的整体行为？如何判断某一种工程改造真正有用？如何区分生物学机制产生的效果与模型自身引入的偏差？又如何利用模型帮助我们设计下一次实验？

后来，我们将这些计算能力逐步组织为 Friskoli-CAD。

**模型不仅是项目结果的展示方式，也是我们不断修改项目设计的重要工具。**

# 01 / WHY WE MODEL

## A Problem Across Scales

### 一个横跨多个尺度的研究问题。

Friskoli 的核心假设是，细菌趋化可能通过改变细胞的空间分布，增加细胞与目标底物之间的有效接触。

这个假设看起来非常直观。

如果某个区域存在更高浓度的引诱物，细菌可能向该区域富集。如果引诱物梯度来自底物降解，那么细菌可能间接获得有关底物位置的信息。如果更多细胞接近底物，就可能产生更多局部降解活动。

但从这三个判断出发，并不能直接推导出整个系统必然具有更高的降解效率。

首先，局部降解产物能否形成足够明显的浓度梯度，取决于产生、扩散和消耗之间的关系，降解出的梯度是高是低，是陡是缓，局部扩散和周围环境的源汇是否指出梯度持续，都是实践中的关键问题。

其次，细菌是否能够感知这种梯度，取决于具体的信号转导机制，不同的敏感区间的匹配和不同的适应性都会对菌体的行为产生影响。

再次，即使细胞产生趋化响应，其空间分布仍然受到随机运动、边界条件和细胞间相互作用的影响，究竟是短时碰撞还是长时聚集，又或者细胞直接掠过底物而没有实际接触。

最后，细胞的富集是否能够增加有效降解，还取决于酶活性、底物可及性和接触时间，过低的酶活性会带来更少的释放和梯度。

因此，我们将完整问题拆解为多个可以独立研究的层次。

| 层次     | 名称                         | 核心问题                 |
| ------ | -------------------------- | -------------------- |
| **01** | **Chemical Field**         | 底物降解产物如何产生、扩散和被消耗？   |
| **02** | **Signal Transduction**    | 局部化学环境如何改变细胞内部的趋化信号？ |
| **03** | **Cell Motility**          | 信号如何影响细菌的游动与转向？      |
| **04** | **Spatial Redistribution** | 大量细胞的运动如何改变群体分布？     |
| **05** | **Surface Encounter**      | 细胞是否更频繁地到达并接触目标底物？   |
| **06** | **Substrate Conversion**   | 这些接触变化是否进一步影响底物转化？   |

这些层次共同构成了 Friskoli 的建模框架。

我们的目标并不是将所有生物学细节无限制地加入模型，而是找到能够解释研究问题、具有明确假设并能够接受实验检验的数学描述。

# 02 / THE BEGINNING（待叙述扩充）

### 一切从细菌的随机游动开始。

在模型开发早期，我们首先关注的是细菌运动本身。

对于典型的大肠杆菌，run-and-tumble 是描述其运动行为的一种经典框架。细菌在 run 阶段沿近似持续的方向游动，并在 tumble 事件后重新选择运动方向。即使没有化学梯度，细胞也会通过这种运动不断探索周围环境。而当趋化信号能够调节转向统计时，细胞可能表现出沿化学梯度迁移的群体偏好。

因此，我们最初建立了简化的细菌运动模型。在二维或三维空间中，我们使用随机过程描述细胞位置与方向的变化，并观察不同运动参数对轨迹的影响。

这些早期模拟帮助我们理解了几个重要问题。

首先，细胞趋化并不意味着每个细胞都沿直线前往目标。
其次，单条轨迹很容易受到随机性的影响，因此需要通过多个细胞或多个独立随机种子获得稳定的统计结果。
第三，细胞的转向频率、运动速度和感知灵敏度会共同影响群体分布。
第四，模拟边界并不是无关紧要的技术细节。细胞与边界接触后的处理方式，可能显著改变观察到的空间富集。

这些认识为后续模型提供了基础。

### Early MCP-Based Chemotaxis

在早期阶段，我们关注的并不是“用现成的趋化模型做一次演示”，而是希望直接改造 MCP（Methyl-accepting Chemotaxis Protein）类受体的配体识别能力，让细菌能够识别与纤维素降解相关的目标信号。

这解释了我们为什么从 MCP 开始。

经典 MCP 介导的趋化通路有成熟的实验基础和相对清晰的理论描述，受体适应、信号传递与马达响应都可以被写成可计算的数学形式。对于一支需要先建立计算能力的团队来说，它是一个可靠的起点。

但随着模型逐渐展开，一个问题出现了。

MCP 路线能够描述运动行为，却没有完整回答“纤维二糖怎样进入感知和代谢链”。

受体改造可以改变细胞识别什么，却不容易解释局部降解产物如何形成持续的摄取与信号通量。

2026 年 4 月，我们把注意力转向 PTS，希望用糖摄取过程把局部信号、摄取通量和趋化响应连接起来。

需要说明的是，这次转向发生在建模与设计层面：最初的 MCP 受体改造方案并未按预期实现，而趋化模拟部分保留了下来，成为后续模型的结构基础。（此处需要核对实际运行的微分方程和论文引文）

在后期的测量路线中，我们再次用到了 MCP——但那是天然 MCP–天冬氨酸趋化响应，用于检验测量方法本身能否捕捉趋化现象，与最初的受体改造计划不是同一件事。这两次使用需要在 Wiki 中明确区分，否则读者可能误以为我们在 MCP 与 PTS 之间反复摇摆。

早期 MCP 模型因此仍然具有参考价值。

它可以作为机制对照、模型结构比较和实验测量验证的重要基础。

# 03 / FROM MOTION TO MASS TRANSPORT

## The First Coupled Model

### 从细胞运动，到空间中的物质分布。

仅仅模拟细菌运动，并不足以研究 Friskoli 的核心问题。

我们还需要知道细菌所响应的化学物质来自哪里。
因此，我们进一步将化学物质的空间分布加入模型。

对于可溶性信号物质，我们采用反应—扩散方程作为基础：（核对实际机制和方程）

%% ∂C/∂t = D∇²C + S(x,t) − U(x,t)
其中：
C 表示局部化学物质浓度；
D 表示扩散系数；
S 表示局部产生项；
U 表示局部消耗项。 %%

在存在显著流体运动时，模型还需要加入对流输运项。（可选，我们反正实际上是低对流）

对于 Friskoli 的示范系统，产生项可以与纤维素降解联系起来，而消耗项可以与细胞摄取联系起来。

通过这种方式，化学场不再只是一个人为设置的固定背景。它可以随着细胞与底物之间的相互作用而变化，与此同时，细胞的运动又依赖于它们所经历的化学环境。于是，模型开始形成双向耦合。

化学场影响细胞运动、细胞运动改变局部细胞分布、细胞分布又可能影响化学物质的产生与消耗。

这是我们从单纯的趋化模拟走向主动传质研究的重要一步。

### A Key Question: Can a Gradient Actually Form?==（待补充）==

我们必须首先判断，局部信号是否能够形成足够明显的空间差异。
如果信号产生速度很低，而扩散速度相对较高，那么浓度差异可能很快被削弱。
如果细胞摄取较强，局部信号也可能被迅速消耗。
如果底物分布较为均匀，细胞未必能够获得有意义的方向信息。
因此，我们需要研究信号产生速率、扩散系数、摄取动力学和空间几何之间的关系。
这也是我们后来开展参数扫描与敏感性分析的重要原因。

# 04 / A MOLECULAR QUESTION

## How Does Cellobiose Become a Motility Signal?

### 从纤维二糖，到细菌运动。

Friskoli 的早期工程设计希望利用纤维素降解产生的葡萄糖，通过MCP，建立底物转化与细胞趋化之间的联系。但这很难排除原有葡萄糖趋化的本底影响，改造MCP蛋白对初创团队的难度又过高。

综合来说，我们的期望是摄取、代谢、信号转导和运动调节能够被一个机制统一在一起。

真的有这样的机制吗？

经过一段时间的文献查找与头脑风暴，我们找到了这个在菌体内隐藏的PTS系统。

（此处插入PTSMCP机制图）

不同于MCP，PTS系统下的趋化似乎并不是热门工作，研究中似乎更加注意其异质代谢的能力，这也意味着没有现成的模型，这正是一个绝佳的建模机会（团队在工作中没有直接找到任何PTS趋化相关的模型，如确有此模型，团队也未曾接触过）。
因此，我们需要为工程糖摄取系统建立更加明确的信号模型。

### The PTS System

Phosphotransferase System（PTS）参与大肠杆菌对某些糖类的摄取和磷酸化。在糖类摄取过程中，PTS 蛋白网络的磷酸化状态可能发生变化。相关研究表明，PTS 网络与细菌趋化调控之间存在信号联系。

这为我们研究糖摄取相关的趋化响应提供了依据。

但 PTS 网络本身的行为，与其下游趋化网络的行为需要区分。

已有研究指出，PTS 网络内部的信号传递可以表现出与下游趋化系统不同的动态特征。同时，PTS 相关输入进入趋化信号网络后，可能受到经典趋化适应机制的调节。因此，我们不能简单地把整个 PTS—趋化系统视为一个没有适应行为的线性通路。也不能在没有实验依据的情况下，为每一个信号环节引入任意的放大作用。（这里可以作为我们未来PTS中揪出AI错误做警示）

### Our PTS Chemotaxis Model

我们尝试建立一个连接糖摄取、PTS 信号状态与细菌运动调控的数学模型。

其逻辑可以概括为：

```mermaid
flowchart LR
    A[糖浓度变化] --> B[糖摄取通量变化]
    B --> C[PTS 相关磷酸化状态变化]
    C --> D[趋化信号网络响应]
    D --> E[CheA / CheY-P 状态变化]
    E --> F[鞭毛马达运动偏好变化]
    F --> G[run-and-tumble 统计变化]
    G --> H[细胞空间分布变化]
```

在这一过程中，我们尤其关注信号方向是否符合已知生物学机制。

例如，对于模型中定义的吸引性糖信号，摄取增强应当通过相应的信号耦合，使细胞产生与吸引性趋化一致的运动偏好。但信号方向正确，只是模型有效性的必要条件之一。我们还需要检查响应幅度、动态时间尺度、适应行为和参数依赖性是否合理。

# 05 / BUILDING THE PTS MODULE==（待人工工作）==

## From Biological Literature to Mathematical Functions

### 如何把生物学机制转化为数学模型？

在建立 PTS 趋化模型时，我们将完整信号过程划分为几个功能部分。

### 5.1 Substrate Uptake

首先，我们需要描述细胞对目标糖的摄取。

在适当的简化假设下，可以使用饱和动力学关系描述摄取通量与外部浓度之间的联系：

J(C) = Jmax × C / (Ks + C)

其中，Jmax 表示最大摄取通量，Ks 表示相应的半饱和参数。

这一表达式能够描述浓度升高时摄取逐渐趋于饱和的行为。

但它不自动代表完整的 PTS 转运机制。

对于具体的工程糖转运系统，参数应当尽可能来自文献、实验测量或明确标注的假设。

### 5.2 PTS Signal State

摄取通量的变化会影响模型中的 PTS 信号状态。

我们使用适当的状态变量描述相关蛋白的有效磷酸化水平，并研究其随摄取条件变化的行为。

这一层的作用，是将外部糖浓度转换为细胞内部可以参与趋化调控的信号。

在模型验证中，我们需要检查这一转换是否具有正确的单调关系、合理的取值范围和适当的响应时间。

### 5.3 Chemotaxis Signaling

随后，PTS 相关信号进入趋化调控层。

这一部分需要考虑 CheA、CheY 等信号组分与马达调控之间的联系。

对于可能涉及的非线性响应，我们应当区分文献支持的机制与为了计算方便引入的近似。

尤其需要避免将多个未经验证的非线性放大环节简单相乘，从而人为产生过强的趋化灵敏度。

### 5.4 Adaptation

趋化适应是模型中需要特别谨慎处理的部分。

PTS 网络自身不表现出经典趋化意义上的适应，并不意味着 PTS 相关趋化输入在完整细胞中不能表现出适应。

已有研究支持 PTS 相关输入可以通过下游趋化网络受到适应调控。

因此，我们在模型中保留下游适应过程，并将其与 PTS 信号状态区分。

这使模型能够分别讨论：

糖摄取信号的持续变化；

趋化网络对信号的动态响应；

以及适应过程如何影响长期运动偏好。

### 5.5 Motor Response

最终，趋化信号通过运动调控层影响 run-and-tumble 行为。

这一层需要将信号状态转换为具有明确物理含义的运动参数。

例如，马达偏好变化如何对应转向事件的统计变化，需要使用一致的定义与适当的参数。

我们希望避免出现同一个信号在不同模型路径中被重复计算的情况。

通过明确模块之间的输入与输出，可以更容易地检查整个信号链。

# 06 / MODEL ARCHITECTURE

## One System, Multiple Modules

### 一个可以被逐层检查的模型系统。

随着模型复杂度提高，我们逐渐意识到，将所有机制写入单一的计算过程，会给验证和修改带来困难。

如果某个模拟结果出现异常，我们很难判断问题来自化学场、信号网络还是细胞运动。

因此，我们开始采用更加模块化的设计。

在 FriskoliCAD 中，我们希望不同模块具有明确的输入、输出和职责。==（以下表格要与实际实现的模块类型做人工核对）==

| 模块                               | 描述                                   |
| -------------------------------- | ------------------------------------ |
| **Chemical Field Module**        | 描述可溶性物质的空间分布，包括扩散、局部产生与消耗。           |
| **Substrate and Enzyme Module**  | 描述底物分布、局部酶作用及降解产物产生。                 |
| **Uptake Module**                | 描述细胞对目标物质的摄取，并将实际接受的摄取通量提供给下游信号模块。   |
| **PTS Signaling Module**         | 将摄取相关信息转换为趋化信号状态，并处理模型所采用的下游信号与适应机制。 |
| **Motility Module**              | 根据运动调控信号更新细胞运动状态、方向和位置。              |
| **Geometry and Boundary Module** | 处理细胞与空间边界、底物表面和其他几何结构之间的关系。          |
| **Measurement Module**           | 从模拟轨迹与空间分布中计算可比较的统计指标。               |

这些模块共同构成了从化学环境到细胞行为的计算路径。

# 07 / MODEL DBTL（重要，待扩充）

## Every Unexpected Result Is a Question

### 模型开发，也需要 Design–Build–Test–Learn。

在 Friskoli 的研究过程中，数学模型并不是一次完成的。

我们经历了从简化运动模型到空间耦合模型，再到分子信号模型和软件模块化的多个阶段。

每一次扩展都带来了新的能力，也引入了新的问题。

### DBTL I — Can Bacteria Follow a Gradient?

最初，我们希望判断带有趋化偏好的随机运动，是否能够产生预期的群体迁移。

我们建立简化的 run-and-tumble 模型，并观察细胞在不同化学条件下的轨迹。

这一阶段帮助我们建立了运动模型的基础。

### DBTL II — Can Local Degradation Create a Signal?

随后，我们将底物降解与化学扩散联系起来。

我们开始研究局部信号产生是否能够形成足够明显的梯度，以及细胞摄取是否会改变这种梯度。

这一阶段使模型从预设梯度逐渐走向动态化学场。

### DBTL III — How Does PTS Affect Motility?

随着工程设计深入，我们需要建立糖摄取与趋化调控之间的数学联系。

我们开始参考 PTS 与趋化信号相关研究，尝试描述摄取、信号状态、适应与马达响应。

这一阶段使模型能够讨论更具体的工程机制。

### DBTL IV — Is Enrichment Really Chemotaxis?

当我们观察细胞在目标附近富集时，一个新的问题出现了。

这种富集是否全部来自趋化？

如果细胞与表面接触后沿边界滑动，是否也会产生局部驻留？

如果对照组的源强、底物消耗或初始条件不同，比较是否仍然公平？

这些问题促使我们重新检查边界条件、对照设置和测量方法。

我们开始将细胞富集与实际接触分开分析，并要求模型比较具有一致的源项与统计定义。

### DBTL V — Can We Trust the Signal Pathway?

对于 PTS 趋化模型，我们进一步检查每个模块的信号方向和动态响应。

我们关注摄取增加是否产生正确的运动偏好，以及适应机制是否被放在具有文献依据的位置。

我们也检查不同信号模块之间是否存在重复计算或不合理放大。

这推动我们进一步整理模块接口和状态变量。

### DBTL VI — Can the Model Guide Experiments?

随着微流控测量方案的发展，我们开始思考如何将模型输出与实验中真正能够测量的数据联系起来。

模拟可以输出完整的细胞位置与内部状态。

但显微实验通常只能观察有限视野中的细胞影像。

因此，我们需要设计能够同时用于模型与实验的评价指标。

例如，区域内细胞数量、空间分布、到达目标区域的比例，以及这些统计量随时间的变化。

这一阶段将模型开发与 Measurement 联系起来。

# 08 / SENSITIVITY ANALYSIS

## Which Parameters Actually Matter?

### 哪些参数真正决定模型行为？

一个模型即使能够产生预期结果，也可能对某些参数高度敏感。

如果轻微改变参数就会使结论完全反转，那么我们需要谨慎评价结果的稳健性。

因此，我们希望通过敏感性分析，研究不同参数对模型输出的影响。

### 8.1 Transport Parameters

首先，我们关注化学物质的扩散系数。

扩散速度决定了局部浓度差异如何随时间和空间变化。

同时，局部信号产生速率与细胞摄取能力也会影响梯度强度。

通过联合分析这些参数，我们可以研究什么条件下能够形成有效的化学信号。

### 8.2 Motility Parameters

其次，我们关注细胞运动参数。

例如，游动速度、基础转向频率以及运动方向变化的统计特征。

这些参数决定细胞在没有趋化信号时的空间探索行为，也会影响趋化响应的最终表现。

### 8.3 Signaling Parameters

对于 PTS 趋化模型，我们关注摄取半饱和参数、信号耦合强度、适应速率和马达响应特征。

我们希望明确哪些参数决定信号灵敏区间，哪些参数影响动态响应，以及哪些参数主要改变长期行为。

### 8.4 Geometry and Boundary Parameters

细胞与目标表面之间的相互作用也需要纳入敏感性分析。

例如，目标几何尺寸、边界运动规则和观察区域定义，都可能影响接触统计。

如果某个富集结果主要由边界处理方式决定，我们就不能将它直接归因于趋化。

### 8.5 From Parameters to Predictions

我们希望通过敏感性分析回答：

哪些参数对结果影响最大？

哪些参数的变化几乎不影响结论？

是否存在使趋化招募效果显著变化的参数区间？

模型在文献支持的参数范围内是否保持稳定？

哪些参数最值得通过实验优先测量？

最终，敏感性分析不仅帮助我们评价模型，也帮助我们安排后续实验。

# 09 / FROM ARRIVAL TO DEGRADATION

## What Should We Measure?

### 从到达、接触，到真正的降解。

在模型研究中，我们逐渐发现，仅仅使用细胞富集倍数不足以完整评价趋化招募。

因此，我们希望建立分层评价指标。

| 步骤 | 模块 | 核心问题 |
|---|---|---|
| **01** | **Signal** | 首先，研究目标附近是否形成可感知的化学梯度。 |
| **02** | **Response** | 其次，研究细胞内部的趋化信号是否发生预期变化。 |
| **03** | **Arrival** | 第三，研究细胞是否更快到达目标区域。 |
| **04** | **Contact** | 第四，研究细胞与底物表面的接触频率和接触时间。 |
| **05** | **Conversion** | 第五，研究这些变化是否能够进一步影响底物转化。 |

这些指标之间具有联系，但并不等价。

例如，细胞可能在目标附近富集，却没有显著增加有效接触；也可能增加接触，但由于酶活性限制而没有明显提高底物降解。

因此，我们希望分别分析每个环节，通过这种方式，我们可以更准确地判断趋化招募效应在哪一层发挥作用，以及在哪一层受到限制。

# 10 / MODEL AND EXPERIMENT（待实际数据补充）

## Connecting Simulation to Reality

### 让模拟结果能够接受实验检验。

模型能够输出大量实验中难以直接观察的状态。例如，完整的化学浓度场、每个细胞的内部信号变量，以及整个模拟空间中的细胞轨迹。但真实实验受到显微视野、成像分辨率、实验时间和设备条件的限制。因此，模型与实验之间需要建立共同的测量语言。

对于微流控实验，我们关注细胞在受控化学条件下的运动和空间分布。
对于模型，我们可以在相应的几何结构和边界条件下，计算相同的统计指标。

这使我们能够比较：细胞分布是否具有相似趋势？空间富集是否随时间变化？不同梯度条件是否产生不同响应？模型是否高估或低估了细胞的运动偏好？

如果实验与模型存在差异，我们需要进一步判断差异来自参数、机制、几何条件还是测量误差。

这也是 Friskoli 模型长期承担 DBTL 功能的重要原因。

模型可以帮助提出实验问题。

实验可以帮助约束模型参数。

而两者之间的差异，可以推动下一轮研究。

# 11 / AI-ASSISTED VISUAL MEASUREMENT（待实际模型补充）

## From Microscopy Images to Quantitative Data

### 让计算机帮助我们观察细菌。

为了将微流控实验与数学模型联系起来，我们还尝试建立基于计算机视觉的图像分析方法。

显微成像能够记录细菌在实验环境中的运动。

但原始图像并不能直接给出细胞数量、运动轨迹或趋化程度。

因此，我们需要将图像转换为可以分析的数据。

### Image Acquisition

首先，实验装置获取细菌在不同时间的显微图像。

成像质量、视野大小、照明条件和时间分辨率都会影响后续分析。

### Object Detection

随后，我们尝试利用目标检测模型识别图像中的细菌。

在这一过程中，我们需要准备适当的训练数据，并检查模型对不同图像条件的适应能力。

### Tracking and Spatial Statistics

在具备足够识别质量的条件下，可以进一步分析细胞的位置变化与空间分布。

如果需要研究单细胞运动，还需要考虑跨帧关联与轨迹追踪。

仅仅检测每一帧中的细胞，并不能自动得到可靠的单细胞轨迹。

### Chemotaxis Quantification

最后，我们希望将图像分析结果转换为与数学模型可比较的指标。

例如，目标区域中的细胞占比、空间密度变化，以及不同实验条件之间的分布差异。

如果能够获得可靠轨迹，还可以进一步研究速度、方向变化和到达时间。

### Validation of the AI Model

计算机视觉模型本身也需要接受验证。

我们需要评价检测准确性、漏检、误检、不同细胞密度下的表现，以及这些误差对最终趋化指标的影响。

因此，AI 视觉模型不仅是一个辅助软件工具，也是整个 Measurement 体系中的重要计算模型。

# 13 / MODEL LIMITATIONS

## What Our Models Can and Cannot Tell Us

### 模型能够解释什么，又不能证明什么？

任何数学模型都需要简化真实世界。

Friskoli 的模型也不例外。

我们使用有限数量的状态变量描述复杂的细胞信号网络。

使用简化的运动规则描述真实细菌的游动行为。

使用连续浓度场描述化学物质的空间分布。

使用特定的几何边界和相互作用规则描述细胞与底物之间的接触。

这些简化使计算成为可能，也带来了适用范围上的限制。

首先，模型中的参数不一定全部具有直接实验测量依据。

其次，特定的边界条件可能影响细胞的空间富集。

第三，部分信号模块采用的近似关系可能无法完整反映真实细胞的动态行为。

第四，模拟中的底物降解与细胞接触关系，需要通过实验进一步约束。

第五，地面低对流模型不能自动代表真实微重力生物反应器中的全部流体行为。

因此，我们希望明确区分：

由数学定义直接决定的模型行为；

通过数值计算得到的模拟结果；

由文献支持的生物学机制；

以及仍然需要实验检验的工程预测。

我们也希望公开重要的参数来源、数值设置、对照条件和模型限制，使读者能够判断结果的可信程度。

# 14 / WHAT MODELING TAUGHT US

## Learning Through Computation

### 我们从模型中学到了什么？

Friskoli 的模型工作始于一个简单的问题：细菌能否通过趋化更有效地接近底物？

随着研究深入，我们逐渐发现，这个问题需要更加谨慎的表达。

趋化响应不一定伴随着可观的空间富集，空间富集也不必然增加有效接触，而有效接触也不是唯一影响底物转化的因素。

而模拟中观察到的任何一种现象，都可能受到参数、边界条件和数值实现的影响。

虽然这些问题很复杂，也让我们在测试中不断加班，受挫，重构模型，但这些认识并没有削弱我们继续研究趋化招募的兴趣。相反，它们帮助我们建立了更加明确的研究目标。

我们开始关注每个环节的独立验证，重视对照条件的一致性，检查分子信号模型是否具有正确的生物学依据，也开始尝试将模拟结果与真实实验中的测量指标联系起来。

模型的价值因此不再局限于预测一个最终结果，它还能帮助我们识别不确定性，发现设计中的薄弱环节，并决定哪些实验最值得优先开展。
